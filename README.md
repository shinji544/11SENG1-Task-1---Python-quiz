# 11SENG1-Task-1---Python-quiz
You will have to install customtikinter and PIL (pillow) to run this software.

Steps to install these libraries:
1. Go to your search bar (usually at bottom left) and search up "command prompt"
2. In command prompt, type "pip3 install customtkinter" (without the "") to install customtkinter and "pip install pillow" for PIL.
3. If these dont work, you might have to install pip. You have to type "python get-pip.py". If this doesn't work, search it up
